# 会议与进度记录

## 每次站会（10 分钟）

每人只回答：

1. 上次以后完成了哪个可验收结果？
2. 下一次站会前要完成什么？
3. 有什么阻塞，需要谁在什么时候协助？

## 周会记录模板

```markdown
# 第 X 周项目周会（YYYY-MM-DD）

## 出席
- M1：
- M2：
- M3：
- M4：
- M5：
- M6：

## 本周可演示成果
- 用户：
- 学籍：
- 选课：
- 图书馆：
- 商店：
- 医院：

## 质量状态
- main 构建：通过/失败
- 自动测试：通过数/失败数
- P0/P1 缺陷：
- 本周版本标签：

## 决策
- 决策、原因、负责人、影响：

## 风险与阻塞
- 风险、影响、解决动作、负责人、截止时间：

## 下周阶段目标
- 团队目标：
- 各模块目标：
```

会议记录放入 `docs/progress/`，文件名为 `YYYY-MM-DD-week-N.md`。涉及架构基线的决定另建 `docs/decisions/ADR-xxxx-标题.md`，避免重要决定只存在聊天记录中。
