# 开发环境统一规范

## 1. 团队统一版本

教师已明确 Java 版本不限。为利用全员已经安装好的环境并减少重复配置，本组统一采用 JDK 25。

| 项目 | 统一标准 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11 x64 | 与 Access 和机房环境保持接近 |
| JDK | JDK 25，Windows x64 | Oracle JDK、Temurin 等发行版均可；组内优先使用同一安装包 |
| Java 语言/字节码 | Java 25 | Maven 编译目标固定为 release 25 |
| Maven | Apache Maven 3.9.16 | 不使用预览版 Maven 3.10 或 Maven 4 |
| Git | Git for Windows 2.x | 使用仓库的 `.gitattributes` 统一换行 |
| IDE | IntelliJ IDEA Community Edition | 六人统一使用；Project SDK、语言级别和 Maven Runner 均为 JDK 25 |
| 编码 | UTF-8 | Java、XML、Markdown、SQL 全部统一 |
| 时区 | Asia/Shanghai | Maven JVM 已通过 `.mvn/jvm.config` 固定 |
| 数据库 | Access `.accdb`，文件名 `vCampus.accdb` | Access/驱动具体版本须再与机房确认 |

JDK 的补丁版本（如 25、25.0.1、25.0.3）可以不同，但大版本必须是 25。若方便，组长应在群文件中共享同一份安装包和 SHA-256。

## 2. JDK 是什么

JDK（Java Development Kit）是 Java 开发工具包，包括：

- `java`：运行编译后的程序。
- `javac`：把 `.java` 源代码编译为 `.class`。
- `javadoc`：生成课程要求的 HTML 源代码帮助文档。
- Java 标准库和调试、打包等工具。

JDK 25 表示本项目可以使用 Java 25 的语法、标准库和字节码。JDK 不是 IDE：IntelliJ IDEA 是编写和调试代码的工具，仍需要指定 JDK 才能编译运行。

## 3. 为什么本组可以使用 JDK 25

- 教师最新说明 Java 版本不限，优先级高于课程材料中的旧版兼容建议。
- 6 名成员已经下载 JDK 25，统一现有环境比重复安装 JDK 8 更简单。
- Swing、Socket、多线程、序列化和 JDBC 在 JDK 25 中仍可使用。
- Maven 会固定编译版本并检查运行 Maven 的 Java 大版本，防止成员混用 JDK。

本项目不再要求兼容 JDK 8。最终答辩和部署电脑必须安装 JDK 25，或者将对应运行时与发布包一起准备。答辩前至少在实际演示电脑上完整启动一次客户端、服务器端和数据库。

## 5. Windows 配置

统一安装顺序：JDK 25 → Maven 3.9.16 → Git for Windows → IDE。JDK 已经安装并能通过版本检查的成员不重复安装。

官方入口：

- Oracle JDK 25：https://www.oracle.com/java/technologies/downloads/
- Apache Maven 3.9.16：https://maven.apache.org/download.cgi
- Git for Windows：https://git-scm.com/install/windows
- IntelliJ IDEA：https://www.jetbrains.com/idea/download/

### 5.1 安装 JDK 25

1. 在 Oracle 下载页选择 `Java SE Development Kit 25`、`Windows`、`x64 Installer`，下载 `.exe`，不要下载 JRE。
2. 双击安装，普通成员保持默认目录即可，例如 `C:\Program Files\Java\jdk-25`。
3. Windows 搜索“编辑系统环境变量”→“环境变量”。在“用户变量”中新建：变量名 `JAVA_HOME`，变量值填写实际 JDK 目录，末尾不要写 `\bin`。
4. 编辑用户变量 `Path`，新增 `%JAVA_HOME%\bin`。
5. 关闭旧终端，重新打开 PowerShell，运行 `java -version` 和 `javac -version`，两者都应显示 25。

已经使用压缩包安装 JDK 的成员，`JAVA_HOME` 指向解压后包含 `bin`、`lib` 的那一层目录。

### 5.2 组长电脑设置 JAVA_HOME

组长电脑当前 JDK 位于 `D:\jdk-25`，可设置用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable('JAVA_HOME', 'D:\jdk-25', 'User')
```

在用户 `Path` 中确保 `%JAVA_HOME%\bin` 存在，并避免另一个 Java 路径排在它前面。关闭并重新打开终端，然后检查：

```powershell
java -version
javac -version
```

两项都应显示 25。其他成员使用自己的实际 JDK 25 安装目录，不能照抄组长路径。

### 5.3 安装 Maven

1. 从 Apache Maven 官方页面下载 `apache-maven-3.9.16-bin.zip`，不要下载 `src` 源码包或 Maven 4 预览版。
2. 解压到不含中文和空格的固定目录，例如 `D:\tools\apache-maven-3.9.16`。
3. 在 Windows“用户变量”中新建 `MAVEN_HOME`，变量值填写 Maven 解压目录。
4. 编辑用户变量 `Path`，新增 `%MAVEN_HOME%\bin`。
5. 关闭旧终端，重新打开 PowerShell，运行 `mvn -version`。

结果必须同时包含 `Apache Maven 3.9.16` 和 `Java version: 25`。如果显示其他 Java 版本，检查 `JAVA_HOME` 和 Path 的顺序。

### 5.4 安装 Git for Windows

1. 从 Git 官方 Windows 页面下载 x64 安装程序；普通 Intel/AMD Windows 电脑选择 x64，不选 ARM64。
2. 双击安装，初次使用可保持默认选项；Git 安装器中的默认文本编辑器选择不影响使用 IDEA 编写 Java。
3. 安装完成后重新打开 PowerShell，运行 `git --version`，能正常显示 Git 2.x 即可。

也可以在 PowerShell 使用官方提供的 winget 命令：

```powershell
winget install --id Git.Git -e --source winget
```

### 5.5 安装 IDE

六位成员统一安装免费的 IntelliJ IDEA Community Edition，不使用 Ultimate 专有功能，避免试用到期或成员功能不一致。

1. 从 JetBrains 官方下载页选择 Windows 的 Community Edition 并完成安装。
2. 启动后选择 `Open`，打开仓库根目录；看到根目录 `pom.xml` 后按 Maven 项目导入。
3. 在 Project Structure 中把 Project SDK 和 Language level 设置为 JDK 25。

## 6. IDE 设置

- Project SDK：JDK 25。
- Project language level：25。
- Maven Runner JRE：Project SDK / JDK 25。
- 编码：Global、Project、Properties 均为 UTF-8。
- 通过根目录 `pom.xml` 导入项目，不手工建立互不一致的普通 Java 工程。

不要提交 `.idea` 等个人 IDE 文件，仓库已统一忽略。

## 7. 每位成员首次克隆后的检查

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check-environment.ps1
mvn validate
```

两个命令都通过后才能开始编码。检查脚本允许不同的 JDK 25 补丁版本，但不允许混用 JDK 8、17、21 等其他大版本。

环境结果无需发到群里；每位成员自行确认四条版本命令和仓库检查脚本均无错误。出现错误时只需把错误截图发给组长协助处理。

## 8. 仓库自动约束

- `.java-version` 声明项目 Java 主版本为 25。
- `pom.xml` 固定 Java release/source/target 为 25，并要求 Maven 3.9.16、JDK 25。
- `.mvn/jvm.config` 固定 UTF-8 和 Asia/Shanghai 时区。
- `.editorconfig` 统一缩进、编码和文件结尾。
- `.gitattributes` 统一文本换行，并保护 Word、Access、JAR 等二进制文件。
- `scripts/check-environment.ps1` 在开发前快速检查 Java、编译器、Maven、JAVA_HOME 和 Git。
