# 项目推进记录

本目录保存能够支撑进度报告、软件设计说明书、测试报告、项目总结和答辩的过程资料。

## 需要立即记录的事件

- 模块完成认领或更换负责人。
- 教师新增/修改要求。
- 技术栈、协议、数据库和模块边界作出决定。
- PR 合并并形成可演示功能。
- 出现超过半天的阻塞、严重缺陷或进度延期。
- 完成阶段版本、测试、演示或答辩彩排。

## 文件说明

- `CURRENT_STATUS.md`：当前阶段、完成情况、下一步和需要组长处理的事项。
- `PROJECT_LOG.md`：按日期记录已经发生的项目事件，只追加不改写历史。
- `RISK_REGISTER.md`：风险、概率、影响、措施、责任 Issue 和状态。
- `TRACEABILITY.md`：需求、设计、Issue、PR、测试和证据之间的对应关系。
- `YYYY-MM-DD-week-N.md`：每周会议与进度记录。

模块负责人在自己的 Issue/PR 中提供原始证据；组长每周把结论汇总到本目录。不要把密码、手机号、学号、真实病历或其他隐私提交到公开仓库。
